# Player Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Write `characters/player/player.gd` - a composition-based player with gravity, forgiving jump feel, animation, and enemy-contact death.

**Architecture:** `CharacterBody2D` root with `PortalMovementComponent` child handling `move_and_collide`. `player.gd` sets velocity each tick, calls `_movement.tick(delta)`, and handles all other concerns inline. Enemy death is triggered by an `Area2D` hitbox child via signal.

**Tech Stack:** Godot 4.x, GDScript

### Task 2: Physics process

**Files:**
- Modify: `characters/player/player.gd`

- [ ] **Step 1: Add `_physics_process` and `_play_anim`**

Append to `characters/player/player.gd`:

```gdscript
func _physics_process(delta: float) -> void:
	# Coyote time: refresh when grounded, drain when airborne
	if _movement.is_grounded:
		_coyote_timer = COYOTE_TIME
	else:
		_coyote_timer = maxf(0.0, _coyote_timer - delta)

	# Jump buffer: set on press, drain each tick
	if Input.is_action_just_pressed("jump"):
		_jump_buffer = JUMP_BUFFER_TIME
	else:
		_jump_buffer = maxf(0.0, _jump_buffer - delta)

	# Gravity
	if not _movement.is_grounded:
		velocity.y = minf(velocity.y + GRAVITY * delta, MAX_FALL_SPEED)

	# Jump: fire when buffer is live and player is eligible
	if _jump_buffer > 0.0 and (_movement.is_grounded or _coyote_timer > 0.0):
		velocity.y = JUMP_FORCE
		_jump_buffer = 0.0
		_coyote_timer = 0.0

	# Horizontal movement
	var move_dir: float = Input.get_axis("left", "right")
	if move_dir:
		velocity.x = move_toward(velocity.x, move_dir * RUN_SPEED, ACCEL * delta)
	else:
		velocity.x = move_toward(velocity.x, 0.0, FRICTION * delta)

	# Aim flip from mouse position
	_sprite.flip_h = get_global_mouse_position().x < global_position.x

	# Animation priority: jump > crouch > run > idle
	if absf(velocity.y) > 50.0:
		_play_anim("jump")
	elif Input.is_action_pressed("down"):
		_play_anim("crouch")
	elif absf(velocity.x) > 20.0:
		_play_anim("run")
	else:
		_play_anim("idle")

	_movement.tick(delta)
	global_position = global_position.round()


func _play_anim(anim_name: String) -> void:
	if _sprite.animation != anim_name:
		_sprite.play(anim_name)
```

### Task 3: Die, respawn, enemy hitbox handler

**Files:**
- Modify: `characters/player/player.gd`

- [ ] **Step 1: Add public interface and hitbox handler**

Append to `characters/player/player.gd`:

```gdscript
func die() -> void:
	if not _alive:
		return
	_alive = false
	_sprite.visible = false
	process_mode = Node.PROCESS_MODE_DISABLED
	died.emit()


func respawn(pos: Vector2) -> void:
	if _alive:
		return
	_alive = true
	global_position = pos
	velocity = Vector2.ZERO
	_sprite.visible = true
	process_mode = Node.PROCESS_MODE_INHERIT


func _on_enemy_hitbox_body_entered(body: Node2D) -> void:
	if body.is_in_group("enemies"):
		die()
```

## Scene setup reminder (user's responsibility)

After the script is done, the user creates `characters/player/player.tscn` in the Godot editor with this structure:

```
CharacterBody2D  [script: player.gd]
├── AnimatedSprite2D          [name must match $AnimatedSprite2D]
├── CollisionShape2D          [shape: capsule or rectangle for player body]
├── PortalMovementComponent   [name must match $PortalMovementComponent]
│                              body export = scene root (CharacterBody2D)
└── Area2D  (name: EnemyHitbox)
    └── CollisionShape2D      [roughly same size as player body collider]
                               collision_layer = 0
                               collision_mask = enemies physics layer
                               body_entered signal -> player.gd::_on_enemy_hitbox_body_entered
```
